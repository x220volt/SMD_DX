03

GETTING STARTED

패치 적용 안내

xdelta 패처에서 아래 원본 파일과 다운로드한 패치를 선택하고, 새 ROM 파일로 저장하세요.

  1. 01

    원본 준비

    헤더 없는 일본판 원본(2 MiB)을 준비합니다. 아래 SHA-256과 일치하는지 확인하세요.

  2. 02

    패치 적용

    xdelta 패처에서 원본과 .xdelta 파일을 선택합니다. 기존 한글화 ROM에 덧씌우지 말고 새 파일로 저장하세요.

  3. 03

    한글 표시 확인

    패치된 파일을 실행해 한글 표시를 확인합니다. 저장 데이터 관련 주의사항도 함께 확인하세요.

ROM 파일도 함께 제공하나요?

아니요. xdelta 패치 파일만 제공합니다. 원본 게임 파일은 포함하지 않습니다.

기존 저장 데이터를 사용할 수 있나요?

기존 저장 데이터와의 호환성은 아직 확정되지 않았습니다. 사용 전 저장 파일을 별도로 백업해 주세요.

오류는 어디에 제보하나요?

패치 공개 시 제보 방법을 함께 안내합니다. 문제가 생긴 화면, 사용한 패치 버전, 재현 과정을 남겨 주시면 확인에 도움이 됩니다.
